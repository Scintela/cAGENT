# 工程规则

本目录是 cAgent 的工程契约：全局纪律、例外登记与可执行检验同址。

| 文件 | 内容 |
|---|---|
| engineering.md | 全局规则，按目标分段：嵌入式 E / 跨系统 P / 轻量 L / 稳定 S |
| exceptions.md | 例外登记——例外必须写明理由与撤销条件，未登记的例外视同违规 |
| checks.sh | 红线检验：`bash rules/checks.sh`，退出码 0 即通过；CI 必须调用同一脚本 |

- 模块级红线规划收录进本目录（modules.md），待 policy 默认语义裁决后建立。
- 规则只引用 ADR 编号、不复述设计理由；修订规则与修订代码同级严肃——先改规则，再改代码。
- 本目录只出中文单语：它是面向贡献者与 AI 结对会话的工程契约，不进双语文档站（文档站 contributing 节有指针页）。
